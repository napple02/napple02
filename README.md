### 🛠 主なツール

**編集・教育（edi-tool）**

- [教育漢字さん](https://edi-tool.github.io/edu-kanji-checker/) — PDF・Word 内の漢字を、小学校での学習学年別に分類
- [常用漢字さん](https://edi-tool.github.io/kanji-checker/) — 常用漢字外（表外漢字）を文脈つきで検出
- [表記統一さん](https://edi-tool.github.io/hyoki-checker/) — 表記ゆれの検出と、統一済み `.docx` の書き出し
- [黒板補正さん](https://edi-tool.github.io/kokuban-adjust/) — 斜めから撮った黒板写真を正面から見た形に補正
- [ページ調整さん](https://edi-tool.github.io/page-count/) — 台割りに合うページ数の提案と背幅の概算

**海・ライフセービング（surf90）**

- [ちがログ](https://surf90.github.io/chiga-log/) — 茅ヶ崎海岸の潮汐・波・水温・天気・注意報
- [ちがビオ](https://surf90.github.io/chiga-bio/) — 茅ヶ崎の海辺〜町中の生き物ガイド（PWA・オフライン対応）
- [tide-PDF](https://surf90.github.io/tide-PDF/) — 1か月分の潮汐表を A4 縦・モノクロ印刷用に出力
- [rescue-sim](https://surf90.github.io/rescue-sim/) — 救助連携シミュレーター［開発中］

### 🧭 つくるときに大事にしていること

1. **インストール不要** — ブラウザだけで完結し、専門知識がなくても使えること
2. **手元で完結** — 原稿や写真をサーバーへ送らないこと
3. **根拠を書く** — 判定基準やデータの出典を README に明示すること
4. **失敗を隠さない** — データを取れなかったときに「異常なし」「該当なし」と表示しないこと

詳しくは [開発原則（edi-tool/.github）](https://github.com/edi-tool/.github/blob/main/PRINCIPLES.md) にまとめています。
